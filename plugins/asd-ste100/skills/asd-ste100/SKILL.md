# ASD-STE100

## 용어와 표현

| 항목 | 지시사항 |
|---|---|
| 용어 선택 | 회사·산업·분야에서 승인한 용어를 사용합니다. 없으면 짧고 쉬운 명칭을 선택합니다. |
| 용어의 이해 | 지역어·속어·은어를 기술 명칭으로 사용하지 않습니다. |
| 용어와 표현의 일관성 | 같은 대상에는 같은 명칭을, 같은 지시에는 같은 표현을 사용합니다. |
| 동작 표현 | 동사는 명사보다 동작을 명확하게 설명합니다. |
| 의미 유지 | 표현을 바꿔도 의미를 유지합니다. 단어별 대체가 부족하면 문장 구조를 바꿉니다. |

## 문장과 문단

| 항목 | 지시사항 |
|---|---|
| 명확성과 정확성 | 문장은 짧고 명확하게 씁니다. 정보는 구체적이고 정확하며 뜻이 분명해야 합니다. |
| 단어 생략 | 문장을 줄이려고 단어를 생략하지 않습니다. |
| 능동문과 수동문 | 능동문을 사용합니다. 설명문에서 행위자를 모르는 경우에만 수동문을 허용합니다. |
| 목록 | 복잡한 내용은 목록으로 구성합니다. 지시와 설명을 같은 목록에 섞지 않습니다. |
| 문장 연결 | 관련 문장은 연결어와 핵심 표현으로 연결합니다. |
| 설명의 전개 | 정보는 점진적으로 제시합니다. 설명문은 문장별로 한 주제를 다루며 명령형을 쓰지 않습니다. |
| 문단 구성 | 문단은 주제문으로 시작하여 관련 정보를 묶습니다. 문단별로 한 주제, 최대 여섯 문장을 씁니다. |
| 괄호 | 참조·식별번호·작업단계·약어·보충설명·대안 표시에 괄호를 사용할 수 있습니다. |

## 작업 지시와 주석

| 항목 | 지시사항 |
|---|---|
| 작업 지시 | 명령형으로 작성하고 작업 순서를 표시합니다. |
| 문장별 지시 | 한 문장에 지시 하나를 씁니다. 동시 작업은 함께 지시할 수 있습니다. |
| 단계별 문장 | 동시 작업이나 작업 직후의 결과는 한 단계에 여러 문장으로 작성할 수 있습니다. |
| 작업 조건 | 독자가 먼저 알아야 할 조건은 지시 앞에 쓰고 쉼표로 구분합니다. |
| 주석 | 정보만 설명하며 지시·요구사항·제한값을 넣지 않습니다. |

## 안전 지시

| 항목 | 지시사항 |
|---|---|
| 위험과 행동 | 위험 수준을 표시합니다. 명확한 행동이나 조건으로 시작하고 위험·결과를 설명합니다. |

## 일반 권고

| 항목 | 지시사항 |
|---|---|
| 대명사 | 대명사가 모호하면 해당 명칭으로 바꿉니다. |
| 지시 대상 | 지시 대상이 모호하면 해당 맥락을 다시 제시합니다. |
| 중립적 표현 | 편견·차별을 피하는 중립적인 표현을 사용합니다. |
